# Bloch-Sphere-Visualization-of-Quantum-Gates-using-Qiskit
This project explores how fundamental quantum gates transform a qubit state using Qiskit. Starting from the |0⟩ state, various single-qubit gates are applied and visualized on the Bloch sphere.  Additionally, an interactive web application was developed to allow users to apply these gates and observe state evolution in real time.
# Features
Apply quantum gates:
Hadamard (H)
Pauli-X (X)
Pauli-Z (Z)
Phase (S)
Identity (I)
Visualize qubit states on the Bloch sphere
Interactive web interface for experimentation
# Technologies Used
Python
Qiskit
Jupyter Notebook
HTML, CSS, JavaScript
# Example
Applying the Hadamard gate transforms |0⟩ into a superposition state located on the equator of the Bloch sphere.
